# Payflow

แพลตฟอร์ม HR และ Payroll ที่พัฒนาเอง โดยเริ่มจาก Payroll Core แล้วขยายสู่ Thai Payroll, Time Attendance และ Employee Self-Service (ESS)

## ทีม

- เจ้าของโปรเจกต์: กำหนดทิศทาง กฎธุรกิจ และตรวจรับผลคำนวณ
- เพื่อนร่วมทีม: ร่วมพัฒนาและตรวจสอบงาน โดยแบ่งหน้าที่ตามความถนัด
- Codex: ผู้ช่วยออกแบบระบบ เขียนโค้ด ทดสอบ และจัดทำเอกสาร

## เป้าหมายรุ่นแรก

รองรับบริษัทเดียวและพนักงานเงินเดือนรายเดือน เพื่อให้สามารถตรวจสอบและปิดงวดเงินเดือนได้อย่างถูกต้อง

- ข้อมูลพนักงานและการจ้างงาน
- ประวัติเงินเดือนพร้อมวันที่มีผล (effective date)
- รายได้และรายการหัก
- นำเข้าข้อมูล OT และรายการปรับจาก Excel/CSV
- คำนวณเงินเดือน รวมกรณีเข้า–ออกและปรับเงินเดือนกลางงวด
- ตรวจผลคำนวณ ปิดงวด และออกสลิปเงินเดือน

## แผนพัฒนา

| ระยะ | ขอบเขต |
| --- | --- |
| 1 — Payroll Core | Employee, Salary History, Earning/Deduction, Payroll Run, Payslip |
| 2 — Thai Payroll | ภาษี ประกันสังคม PVD OT โบนัส และไฟล์ธนาคาร |
| 3 — Time + ESS | ลงเวลา กะงาน การลา ขอ OT และการอนุมัติ |
| 4 — Enterprise | หลายบริษัท การแยกข้อมูลและสิทธิ์ API และเชื่อมระบบบัญชี |

## หลักการออกแบบ

- ข้อมูลที่มีผลต่อเงินเดือนต้องรองรับวันที่มีผลและประวัติย้อนหลัง
- ผลคำนวณต้องอธิบายที่มาและตรวจสอบซ้ำได้
- กฎการปัดเศษและการคิดเงินเดือนตามสัดส่วนต้องกำหนดอย่างชัดเจน
- งวดที่ปิดแล้วต้องมีการควบคุมการแก้ไขและบันทึกการปรับย้อนหลัง
- ข้อมูลเงินเดือนต้องมีการควบคุมสิทธิ์และบันทึกการเปลี่ยนแปลง
- ก่อนจ่ายเงินจริง ต้องตรวจเทียบผลกับงวด Payroll จริงและตรวจรับกฎที่เกี่ยวข้อง

## สถานะปัจจุบัน

เริ่มต้นโปรเจกต์และกำหนดขอบเขต ยังไม่มีระบบคำนวณที่พร้อมใช้งานจริง

งานถัดไปคือออกแบบ Payroll Data Model และ Calculation Flow ก่อนเริ่มพัฒนา Payroll Core โดยเทคโนโลยีและวิธีติดตั้งจะระบุเมื่อเลือกโครงสร้างระบบแล้ว
